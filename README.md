# Стабилизация ориентации КА с помощью обучения с подкреплением (PPO)

Продолжение курсовой «Оптимальное управление ориентацией космического аппарата
с использованием кватернионной алгебры»
(https://github.com/Snackkie/spacecraft_stabilisation).

## Файлы

| Файл | Что внутри |
|---|---|
| `attitude.py` | параметры аппарата из прошлой работы, модель движения (RK4 + нормировка кватерниона), метрики, CasADi в двух постановках, ПД-регулятор |
| `ppo.py` | векторизованная среда и алгоритм PPO на чистом NumPy, обучение |
| `evaluate.py` | сравнение регуляторов, графики и `results/results.json` |
| `ppo_dr.npz`, `ppo_nominal.npz` | веса обученных агентов (с рандомизацией и без) |
| `*_log.json` | журналы обучения |
| `results/` | графики и численные результаты |

## Запуск

Нужны только `numpy`, `matplotlib`, `casadi` (PyTorch не требуется).

```bash
pip install numpy matplotlib casadi
python evaluate.py                               # сравнение (~20 мин, в основном CasADi)

# обучение заново (~30 мин на агента на одном ядре)
python ppo.py --name ppo_dr --dr --steps 5000000
python ppo.py --name ppo_dr --dr --steps 7000000 --lr 1.5e-4 --resume ppo_dr.npz
```

Приведённые агенты обучены за 9.3 млн шагов: 5 млн шагов основного этапа и
4.3 млн шагов дообучения (второй этап остановлен досрочно).

## Постановка

* Параметры аппарата как в прошлой работе: I = diag(10, 10, 10), τ_max = 0.1 Н·м,
  горизонт 120 с, номинальный сценарий q0 = [0.707, 0.707, 0, 0], ω0 = [0.9, 0.5, 0.5].
* Агент принимает решение раз в 0.5 с.
  * Наблюдение: кватернион ошибки и угловая скорость.
  * Действие: момент в пределах ±τ_max.
* Вознаграждение: −θ/π − 0.5|ω| − 0.01|a|²/3 + 1 в допуске (θ < 2°, |ω| < 0.01 рад/с).
* Рандомизация при обучении:
  * моменты инерции ±20 % плюс центробежные ±0.5;
  * постоянный возмущающий момент до 3 % от τ_max;
  * шум измерений.
* Все регуляторы проверяются на одной «истинной» модели: RK4, 4 подшага, нормировка кватерниона.
